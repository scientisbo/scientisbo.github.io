# Mobile Robot Spatial Interaction Navigation and Target Following System

## Overview

This project focuses on mobile robot navigation in spatial interaction scenarios. I built a ROS/Gazebo-based simulation system for target following, dynamic obstacle avoidance, pedestrian motion modeling, and GUI-based control.

## My Role

I served as the project leader and was responsible for algorithm design and system implementation.

My main contributions include:

- Implemented target tracking and following logic
- Built a randomized pedestrian motion model
- Implemented an artificial potential field based path planning module
- Designed an adaptive speed control strategy based on crowd density
- Conducted multiple rounds of parameter tuning and logic optimization
- Evaluated system response delay and obstacle avoidance performance

## Technical Stack

- ROS
- Gazebo
- RViz
- Python / C++
- Path planning
- Target following
- Dynamic obstacle avoidance
- GUI-based robot control

## Key Results

- Control response delay: no more than 0.1 seconds
- Obstacle avoidance success rate: 95% in 20 simulation experiments
- Completed 8 rounds of parameter and logic optimization

## Key Challenges

### Dynamic obstacle avoidance

The main challenge was to maintain stable target following while avoiding randomly moving pedestrians. I addressed this by combining pedestrian motion modeling, artificial potential field based path planning, and adaptive speed control.

### System-level debugging

The project required debugging across simulation, planning, control, and visualization modules. I improved the robustness of the system through repeated testing and parameter tuning.
